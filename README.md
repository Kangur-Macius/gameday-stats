# Bentleigh Greens Matchday Stats — PWA v3

## Deploy to GitHub Pages
1. Create a new GitHub repo (e.g. `bg-matchday-stats`)
2. Upload all files in this folder to the repo root
3. Go to Settings → Pages → Deploy from branch → main → / (root) → Save
4. Live at: https://yourusername.github.io/bg-matchday-stats/

## Install on iPhone (Safari)
Open URL → Share → Add to Home Screen → runs fullscreen, works offline

## Install on Android (Chrome)
Open URL → ⋮ → Add to Home Screen
